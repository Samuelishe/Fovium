# Fovium resources policy

Role: Contract for source-controlled assets shipped with or used to verify Fovium.
Read when: Adding an image, icon, font, generated asset, or test image corpus.
Authoritative for: What may be committed beneath `resources/` and its provenance requirements.
Not authoritative for: Runtime resource loading, application packaging, or dependency versions.

Curated assets intended to ship with Fovium will live under `resources/`. Every externally sourced or adapted asset must have its source, author, license, and use recorded in [`docs/THIRD-PARTY.md`](../docs/THIRD-PARTY.md) before it is committed.

Do not commit unverified internet images or raw generation dumps. Test image corpora must have known provenance and compatible terms or be generated by the project with that method recorded. User photographs and runtime data never belong in this directory.

No image, icon, font, logo, translation catalog, or test-image asset has been introduced through CONTRACTS-R1.
