# README visual assets

`fovium-hero.jpg` is a capture of the real Windows Fovium assembly displaying a deterministic synthetic scene created
by `eng/branding/capture-readme-hero.ps1`. The ignored capture host sets `en-US` before entering Fovium so the public
artwork remains English without changing product settings. The scene, capture, and composition were made specifically
for Fovium. No owner photograph, downloaded photograph, stock asset, private path, or third-party font file is present.

The final composition uses the Photo Info candidate because it shows that secondary UI remains restrained while the
photograph stays primary. The zero-UI candidate, English Settings evidence, and uncomposed captures remain ignored
under `artifacts/branding/` for visual review. A separate pass launches the actual `Fovium.exe` to verify Viewer and
Settings native window icons; the culture-controlled host is used only for public artwork.
